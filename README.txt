ソフトテニス戦術ボード Ver.5.3（PWA）

公開方法：ZIPを展開し、index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png の5ファイルをGitHub Pagesの公開フォルダに配置してください。
公開URLをChrome（Android）で開き、メニュー→「ホーム画面に追加」または「アプリをインストール」を選びます。
PCでのローカルHTML起動ではPWAインストールはできません。
オフライン利用はHTTPSで一度開き、キャッシュされた後に対応します。
保存データはブラウザの設定や削除操作で消える場合があります。
